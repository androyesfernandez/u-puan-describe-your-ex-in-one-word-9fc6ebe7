on make.fun: a program that writes exactly one word — `Decaf` — into
`/output/entry.txt`, and nothing else.

The word is the whole verdict. It looks like the real thing and does
nothing: all the ritual, no buzz. One word, five letters, no newline,
no punctuation.

Run it with Node 22 and no network:

```sh
node main.ts
```
